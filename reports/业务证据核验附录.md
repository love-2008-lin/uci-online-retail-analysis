## 口径与计算方法

| 指标            | 分子与分母或计算步骤                                                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 重复方案          | 在 `2011-10-01 ≤ InvoiceDate < 2011-11-01` 范围按原 8 列分别整组隔离、每组留首条、保留全部。对每套结果排除缺发票号、C/c 开头及数量或单价非正，再数行并对 `Quantity × UnitPrice` 求和 |
| 每组留一条的金额差异    | (1,151,263.73 − 1,148,101.10) ÷ 1,148,101.10 ≈ 0.28%，以当前整组隔离金额为基准                                                              |
| 最大客户占比        | 先按市场和非缺失 `CustomerID` 汇总金额。取最大值除以该市场全部有效正向金额。荷兰为 39,995.95 ÷ 40,708.65，澳大利亚为 16,471.77 ÷ 17,150.53                             |
| 发票中位数         | 按市场、`InvoiceNo` 汇总有效行金额，再取市场内发票金额中位数。偶数张取中间两张的均值                                                                               |
| 去最大一张后的均值     | (市场总额 − 最大一张金额) ÷ (有效去重发票数 − 1)。荷兰为 (40,708.65 − 20,277.92) ÷ 14，澳大利亚为 (17,150.53 − 15,643.77) ÷ 3                             |
| `23084` 数量集中度 | 取精确编码 `23084`，按 `InvoiceNo` 汇总数量，取前三票的 4,272 件 ÷ 全部 6,323 件，得到 67.56%                                                          |
| 缺客户标识金额占比     | 只加总缺 `CustomerID` 的有效行金额 GBP 115,582.05，除以全部有效金额 GBP 1,148,101.10，得 10.07%                                                     |
| 缺客户标识发票占比     | 对至少有一行缺 `CustomerID` 的发票去重，111 ÷ 全部 2,040，得 5.44%。同一发票如有其他有效行，金额指标仍只计缺标识的行                                                     |
| 缺客户标识明细占比     | 9,738 ÷ 57,834，得 16.84%                                                                                                        |
| 手工项金额         | 从原始 10 月窗口按指定客户、市场、精确商品编码 `M` 及发票筛选，保留带符号数量，逐行用数量乘单价再按发票相加                                                                     |

重复组统计的中间结果如下。按原始窗口的组成员与额外行定义分别得到 1,482 与 773；应用后续条件后才比较有效行数。

| 重复方案  | 处理重复后行数 | 后续取消行数 | 后续非正行数 | 最终有效行数 |
| ----- | -------:| ------:| ------:| ------:|
| 整组隔离  | 59,260  | 1,188  | 238    | 57,834 |
| 每组留一条 | 59,969  | 1,194  | 238    | 58,537 |
| 保留全部  | 60,742  | 1,200  | 238    | 59,304 |
